# raysetta

Crystal implementations of [Raysetta](https://github.com/danini-the-panini/raysetta)

## Installation

```sh
$ crystal build src/raysetta.cr --output bin/
```

## Usage

```sh
$ bin/raysetta scene.json -w 1920 -h 1080 -s 500 -d 50 > out.ppm
```
